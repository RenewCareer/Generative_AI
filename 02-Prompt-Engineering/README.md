# ⌨️ Track 2 — Prompt Engineer

> 🔒 **Status: Scaffolded.** This track's full lessons and examples are being built next, after Track 1 (Foundations & Orientation) is complete. This README is a placeholder outlining what's coming.

## What you'll learn

1. **Prompt Engineering Fundamentals** — anatomy of a good prompt, instructions vs context vs constraints, system vs user prompts.
2. **Zero-shot, One-shot, and Few-shot Prompting** — when to use each, how examples steer model behavior.
3. **Chain-of-Thought and Advanced Prompting** — reasoning prompts, self-consistency, ReAct, prompt chaining.
4. **Prompt Optimization and Evaluation** — iterating systematically, A/B testing prompts, rubric-based evaluation.
5. **Prompt Engineering for Chatbots and AI Agents** — multi-turn context management, tool-use prompting, guardrails.

## Prerequisite

Complete [Track 1 — Foundations & Orientation](../01-Foundations-and-Orientation/README.md) first, especially *Python Refresher for AI* and *Introduction to AI & GenAI*.
