# 💻 Track 3 — GenAI Application Developer

> 🔒 **Status: Scaffolded.** This track's full lessons and examples are being built next. This README is a placeholder outlining what's coming.

## What you'll learn

1. **Large Language Models (LLMs) and Transformers** — architecture intuition, tokens, context windows, embeddings.
2. **Building Generative AI Applications using APIs** — calling LLM APIs, streaming, function/tool calling, error handling.
3. **Retrieval Augmented Generation (RAG)** — chunking, embedding, retrieval, grounding responses in your own data.
4. **Vector Databases (FAISS, Pinecone, etc.)** — indexing strategies, similarity search, hybrid search.
5. **Text, Image, and Multimodal AI Applications** — image generation/understanding, audio, combining modalities.

## Prerequisite

Complete [Track 1 — Foundations & Orientation](../01-Foundations-and-Orientation/README.md) and [Track 2 — Prompt Engineer](../02-Prompt-Engineering/README.md) first.
